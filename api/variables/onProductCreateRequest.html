onProductCreateRequest

AI product creation trigger with quota validation, image generation, and CABYS recommendation.

Back to API index

Trigger Contract

/enterprises/{enterpriseID}/product_requests/{productID}

Event type: Firestore onDocumentCreated (Functions v2)

Flow Summary

  • Sets request status to processing.
  • Loads enterprise config info and checks aiProductCreatorAttempts.
  • Generates product sheet base fields from prompt.
  • Runs image generation and CABYS recommendation in parallel.
  • Writes final productSheet JSON and completion status.
  • Decrements aiProductCreatorAttempts when successful.

Status Model

processing generatingProductInfo generatingImage completed completedWithPlaceholderImage errorNoProductCreatorAttempts errorFetchingEnterpriseDetails errorGeneratingProductSheet errorFetchingCabys

Request Example

/enterprises/acme-cr/product_requests/PRD-REQ-2026-0041 

{
  "prompt": "Shampoo organico de 500 ml para mascotas, sin sulfatos"
}

Response Fields Written to Request Doc

  • status
  • loadingValue
  • productSheet (JSON string)
  • error (if applicable)
  • warning_image (only when placeholder image is used)
