onCabysRecommendationRequest

AI-assisted CABYS recommendation flow that receives prompt text and returns ranked CABYS suggestions.

Back to API index

Trigger Contract

/enterprises/{enterpriseID}/cabys_recommendation_requests/{requestID}

Event type: Firestore onDocumentCreated (Functions v2)

Flow Summary

  • Validates prompt in request document.
  • Loads enterprise details for context.
  • Generates simplified product title/description and suggested queries.
  • Fetches CABYS candidates from cache and Hacienda API.
  • Uses Genkit flow to pick main and secondary CABYS recommendations.
  • Writes result JSON and completed status on request document.

Status Model

fetching_enterprise_details generating_simplified_product fetching_cabys_codes recommending_cabys completed error_no_prompt error_cabys_recommendation_flow

Request Example

/enterprises/acme-cr/cabys_recommendation_requests/CABYS-REQ-010 

{
  "prompt": "Servicio mensual de mantenimiento de redes empresariales"
}

Result Fields Written to Request Doc

  • status
  • loadingValue
  • result (JSON string with mainCabysSuggestion and subCabysSuggestions)
  • error (if applicable)
