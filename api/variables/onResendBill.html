onResendBill

Resend trigger for already-issued billing documents, reusing stored artifacts and matching email templates.

Back to API index

Trigger Contract

/enterprises/{enterpriseId}/bills/{billId}/resends/{resendId}

Event type: Firestore onDocumentCreated (Functions v2)

What This Function Does

  • Reads the source bill document and validates recipients.
  • Downloads pdfFileUrl, xmlSentFileUrl, and xmlResponseFileUrl.
  • Loads enterprise logo with storage fallback.
  • Selects email transport by document type: FE, NC, or TE.
  • Sends attachments to all provided recipients.

Expected Request Payload

/enterprises/acme-cr/bills/BILL-2026-00023/resends/RESEND-001 

{
	"recipients": [
		"accounting@acme.cr",
		"auditoria@acme.cr"
	]
}

Status and Failure Modes

resent by email invalid resend data bill does not exist failed to retrieve PDF/XML unsupported bill type

Operational Note

This flow assumes the original bill already completed artifact generation. If XML or PDF URLs are missing in the source bill, resend cannot succeed.
