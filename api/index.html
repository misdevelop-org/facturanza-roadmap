Facturanza Backend API Documentation

This page documents the production API behavior implemented in the backend repository, focusing on the two main runtime surfaces: the functions folder (billing flow) and genkit_features (AI-assisted flows).

Runtime: Node 22 Platform: Firebase Functions v2 Database: Firestore AI: Genkit + Gemini + Imagen

How This Backend Is Structured

functions handles electronic billing workflow.

  • Create XML from a Firestore bill request.
  • Sign XML, submit to Hacienda, confirm result.
  • Store XML/PDF in Cloud Storage and send email.

genkit_features handles AI-assisted product and support workflows.

  • Generate product sheet suggestions and product images.
  • Recommend CABYS and tax mappings.
  • Explain XML errors in Spanish for end users.
Firestore-triggered flows are request-driven. Clients create a request document, and each function updates the same document with status, progress, and final result.

Functions Folder API

onCreateBill

/enterprises/{enterpriseId}/bills/{billId}

Triggered when a new bill document is created. It processes billing end-to-end.

  • Validates subscription and terminal.
  • Builds electronic invoice XML.
  • Signs XML and submits to Hacienda (when enabled).
  • Saves signed XML, response XML, and PDF to storage.
  • Sends invoice/credit-note/ticket email with attachments.
processing signedXml hacienda-accepted completed hacienda-rejected invalidCredentials invalidSignature terminalNotFound subscriptionLimitReached rejectedBillsLimitReached

onResendBill

/enterprises/{enterpriseId}/bills/{billId}/resends/{resendId}

Triggered when users request re-sending a previously issued bill by email.

  • Loads original bill and attachment URLs.
  • Downloads PDF and XML artifacts.
  • Resends with matching template by document type (FE, NC, TE).
resent by email unsupported bill type missing recipients

Genkit API

onProductCreateRequest

/enterprises/{enterpriseID}/product_requests/{productID}

Builds a complete product proposal using AI and CABYS lookup.

  • Checks quota in subscription.aiProductCreatorAttempts.
  • Generates product sheet fields from prompt.
  • Generates and stores image in Cloud Storage.
  • Fetches CABYS options and picks best recommendation.
  • Writes final productSheet JSON in the request doc.
processing generatingProductInfo generatingImage completed completedWithPlaceholderImage errorNoProductCreatorAttempts errorGeneratingProductSheet errorFetchingCabys

onCabysRecommendationRequest

/enterprises/{enterpriseID}/cabys_recommendation_requests/{requestID}

Fast CABYS recommendation flow for a free-text product prompt.

  • Generates simplified product title and queries.
  • Searches Hacienda CABYS API with cache.
  • Returns main and secondary CABYS suggestions.

onProductImageRequest

/enterprises/{enterpriseID}/products/{productID}/image_requests/{requestID}

Regenerates product image from direct prompt or existing productSheet.imagePrompt.

onErrorExplanationRequest

/enterprises/{enterpriseID}/bills/{billID}/explain_error/{requestID}

Explains XML errors in Spanish with legal/accounting context for Costa Rica.
