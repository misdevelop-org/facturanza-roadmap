Sucursales y terminales

Cómo se numeran tus documentos: sucursales, terminales y consecutivos.

Quién puede: Propietario, Administrador y Contador

1. Cómo funciona

Cada documento lleva un consecutivo de 20 dígitos compuesto por sucursal (3) + terminal (5) + tipo de documento (2) + número (10). Facturanza lo administra por ti.

Sucursal

Un establecimiento o sede. Tu empresa nace con la sucursal 001, llamada Principal. Tiene solo un nombre.

Terminal

Un punto de emisión (caja). Cada sucursal nace con la terminal 00001, llamada Principal. Cada terminal lleva su propio consecutivo.

2. Crear y administrar

  • Crear sucursal: escribe el nombre. Se crea con la siguiente numeración (002, 003…) y una terminal Principal.
  • Dentro de una sucursal, Crear terminal.
  • En una terminal ves el Consecutivo actual y puedes Actualizar consecutivo (útil si vienes de otro facturador y debes continuar la numeración). Úsalo con cuidado: un número repetido genera rechazos.
  • En Usuarios ves quiénes están Asignados y quiénes tienen Acceso (ver Roles y acceso).

3. La clave numérica de 50 dígitos

Además del consecutivo, cada comprobante tiene una clave única de 50 dígitos: país (3) + fecha DDMMAA (6) + cédula del emisor (12) + consecutivo (20) + situación (1) + código de seguridad (8). Aparece en el XML y sirve para consultar el documento. En una nota de crédito, referencia la clave del documento original.
